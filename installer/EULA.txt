1. WHAT THIS SOFTWARE DOES

DocCipher Breaker removes editing restrictions from Microsoft Word (.docx)
documents. A .docx file is a ZIP archive containing XML. When a document
author applies "Restrict Editing" in Word, Word records that choice as a
<w:documentProtection> element inside word/settings.xml. That element is an
instruction to Word, not encryption: the document's text is stored in readable
XML whether or not the restriction is present. This software removes that
element and rebuilds the archive.

Be clear about what that means: this restriction is a courtesy lock. It
signals the author's intent that the document not be altered. It is not a
security boundary and was never designed as one.


2. WHAT THIS SOFTWARE DOES NOT DO

This software does NOT decrypt password-encrypted documents. Word can encrypt
a document with a password, producing an entirely different file format (an
encrypted OLE compound file). Those documents are genuinely unreadable without
the password. This software detects them and refuses to proceed. It contains
no password cracking, brute-force, or cryptographic attack capability of any
kind.
